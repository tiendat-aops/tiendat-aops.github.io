💻 Industrial Projects

Symbol Detection & Counting in Architectural Drawings

AI Engineer

  • Built an end-to-end pipeline (PDF → per-class symbol counts → annotated PDF/JSON/COCO) to detect and count small symbols on very large architectural drawings, served via FastAPI.
  • Handled the scale gap (median symbol ≈ 36×36 px) with overlapping sliding-window tiling, RF-DETR detection (31 classes; 99.9% mAP@50, 92.5% mAP@50:95), and global NMS merging.
  • Added DINOv2 embedding classification within symbol groups (~92–93% per-symbol accuracy) and OCR with text-to-symbol matching to separate same-shape symbols with different labels.
  • Raised symbol recall on a real drawing from 92% (201/218) to 98.7% (224/227).

Enterprise AI Assistant for Internal Operations

AI Engineer

  • Enabled document Q&A over attached PDFs/images via multimodal LLMs, persistent chat history, and a switchable model backend (GPT-4o/4.1, Gemini 2.5, DeepSeek).
  • Delivered the full-stack platform (Next.js, Prisma, MongoDB) with role-based access, an admin console, and Dockerized deployment behind Nginx.
