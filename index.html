💻 Selected Projects

Symbol Detection & Counting in Architectural Drawings

End-to-end pipeline for counting small symbols on very large drawings, using sliding-window RF-DETR (31 classes; 99.9% mAP@50) with DINOv2 and OCR to separate look-alike symbols. Raised recall on a real drawing from 92% to 98.7%.

Enterprise AI Assistant for Internal Operations

Full-stack LLM workplace assistant with multi-step tool calling over 30+ typed tools (HR data, Google Calendar, work emails), document Q&A, and confirm-before-send safeguards.

Voice Agent

Real-time helpdesk agent on LiveKit with SIP phone integration and a 7-phase guided dialogue with 10+ stateful function tools, turning each call into a structured work-order ticket.
